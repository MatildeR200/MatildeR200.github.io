PROJETO 07

Sistema de Gestão de Dados Hospitalares

Projeto Académico — Universidade de Coimbra
Bases de DadosSQLSQLiteETLPandasSaúdePython

Objetivo: desenvolver um pequeno sistema de gestão de base de dados para apoiar as tarefas de um hospital — desde o registo do doente à entrada, passando pela triagem, até à decisão médica de internamento ou alta — com interação do utilizador através de menus adaptados a cada perfil profissional.

Este projeto dá continuidade ao projeto de apoio à decisão de internamento de doentes COVID-19: o modelo de classificação desenvolvido nessa fase foi integrado no sistema para apresentar ao médico uma sugestão automática de internamento ou alta.

Processo ETL

O sistema foi construído seguindo as três etapas de um processo ETL:

01 · EXTRAÇÃOLeitura de dados de várias fontes: ficheiros JSON simulando a leitura do Cartão de Cidadão e a ficha do utente, e um ficheiro CSV com os registos de temperatura.
02 · TRANSFORMAÇÃOJunção, seleção e limpeza dos dados com Pandas e NumPy — por exemplo, o cálculo da temperatura a partir dos registos do CSV.
03 · CARREGAMENTOInserção dos dados numa base de dados SQLite, organizada em três tabelas relacionadas pelo identificador do utente.

Estrutura da base de dados

CARTAO_UTENTE

  • 🔑 ID_utente
  • Utente_nome
  • Data_nascimento
  • Genero
  • Localidade

Dados de identificação lidos do Cartão de Cidadão.

FICHA_UTENTE

  • 🔑 ID_utente
  • Dados de identificação
  • ID_hospitalar, Data e Hora de entrada, Contacto
  • Pressão arterial, Ritmo cardíaco, Dificuldade em respirar, Temperatura
  • Idade, Sugestão, Decisão

Ficha clínica completa, preenchida ao longo do percurso do doente.

RELATORIO

  • Data
  • utentes (0 = alta, 1 = internado)

Relatório estatístico de altas e internamentos por dia.

Menus por perfil profissional

A interação foi organizada em menus que refletem o percurso real do doente no hospital, cada um com as operações adequadas a quem o utiliza:

Secretariado

Criar, consultar, atualizar e eliminar a ficha do utente, e consultar o relatório de altas e internamentos. INSERT · SELECT · UPDATE · DELETE

Triagem

Registar os sinais vitais — pressão arterial, ritmo cardíaco, dificuldade em respirar e temperatura — e consultar a ficha. UPDATE · SELECT

Consulta Médica

Consultar a ficha completa, obter a sugestão automática do modelo de classificação e registar a decisão final do médico. SELECT · UPDATE

Utente

Consultar a decisão médica — se teve alta ou se fica internado — a partir do seu identificador. SELECT

Esquema do menu principal e dos menus de cada perfil

Ligação ao modelo de classificação

No menu da Consulta Médica, o sistema calcula uma sugestão de internamento ou alta com base no modelo regressivo desenvolvido no projeto anterior, usando as variáveis selecionadas nessa fase — idade, vacinação, dificuldade em respirar e temperatura. A sugestão fica registada na ficha do utente, mas a decisão final é sempre introduzida pelo médico, que pode ou não seguir a recomendação.

Aplicação em contexto real

Este projeto reproduz, de forma simplificada, o circuito de informação de um serviço de urgência:

  • Informação centralizada: todos os profissionais trabalham sobre a mesma ficha, evitando registos duplicados e em papel.
  • Acesso por perfil: cada profissional vê e altera apenas a informação de que precisa.
  • Apoio à decisão integrado: o modelo de IA é usado no momento certo do circuito, junto da informação clínica.
  • Indicadores de gestão: o relatório de altas e internamentos por dia é a base para dashboards de ocupação e planeamento.

# No menu da Consulta Médica é pretendido que adicionemos para alem das variáveis que a FICHA_UTENTE contem, que adicionemos a idade do utente, a sugestão da decisão do internamento e a decisão médica.

def menu_Consulta():
    opcao = 1
    while opcao>=1 and opcao<=2:
        opcao = int(input('-------------------- Menu Consulta Médica -------------------- '
                                '\n 1 - Consulta da FICHA_UTENTE'
                                '\n 2 - Atualização da FICHA_UTENTE' 
                                '\n Insira a opção que deseja efetuar: '))
        
        # Opcao fora do intervalo
        while opcao < 1 and opcao>2:
            print('Opçao Inválida!')
            opcao = int(input('Insira uma opcao válida: '))

        # Consulta da Ficha do Utente + Idade e decisão Internamento
        if opcao == 1 :
            
            ID_utente = int(input('Insira o ID_utente: '))
            #optei por pedir ao utlizador a idade em ves de usar a data de nascimento
            Idade = int(input('Insira a Idade do utente: '))
            c.execute('UPDATE FICHA_UTENTE SET Idade=%d WHERE ID_utente=%d' %Idade %ID_utente)
            # consulta a ficha do utente    
            ficha_utente = pd.DataFrame(c.fetchall(), columns=['ID_utente','Utente_nome','Data_nascimento','Genero','Localidade','ID_hospitalar', 'Data_Entrada','Hora_Entrada','Contacto_Telefonico','Pressao_Arterial','Ritmo_Cardiaco', 'Dificuldade_Respirar','Temperatura','Idade'])
            print(ficha_utente)

            
            # Sugestão sobre o internamento    
            # baseado na Meta 1 - modelo regressivo (desenvolver os minimos quadrados: (Xt*X)^-1 * XT*y)
            
            c.execute(''' SELECT Idade, Vacinacao, Dificuldade_Respirar, Temperatura
                          FROM FICHA_UTENTE WHERE ID_utente = %d''' %ID_utente)      # variaveis escolhidas 
            
            sugestao = c.fetchone() # Mostrar o 1º registo (1ª linha) do resultado do comando anterior - IDADE 

            paciente = np.zeros((5,1))  # matriz com zeros 
            paciente[0,0] = sugestao[0] # idade
            paciente[1,0] = sugestao[1] # Vacinacao - não há dados mas é importante
            paciente[2,0] = sugestao[2] # Dificuldade em Respirar
            paciente[3,0] = sugestao[3] # Temperatura 
            
            
            PAR = np.array([ 0.006491, -0.39888863, 0.0959522 , 0.00049133]) # parametros da meta 1

            Sugestao = np.dot(paciente,PAR).round() # produto das variveis escolhidas c o parametro
            
            if Sugestao == 0:
                Sugestao = 'tem alta'
            else:
                Sugestao = 'fica internado'
            
            c.execute('UPDATE SET Sugestao = %d FROM FICHA_UTENTE'%Sugestao)
            ficha_utente = pd.DataFrame(c.fetchall(), columns=['ID_utente','Utente_nome','Data_nascimento','Genero','Localidade','ID_hospitalar', 'Data_Entrada','Hora_Entrada','Contacto_Telefonico','Pressao_Arterial','Ritmo_Cardiaco', 'Dificuldade_Respirar','Temperatura','Idade','Sugestao'])
            print(ficha_utente)
            escolha_menu()


        # Atualização da FICHA_UTENTE - ter alta ou ficar internado - 0(sim), 1(não)
        if opcao == 2:
            print('Insira a Data do registo hospitalar: ')
            Data = datatime.now().strftime('%dia/%mes/%ano')  
            
            utentes = int(input('Insira a opção: '
                               '0 - se tiver alta'
                               '1 - se fica internado'))
            
            
            if utentes == 0:
                Decisao = 0 # tem alta 
            
            else:
                Decisao = 1 # fica internado 
    
            c.execute('UPDATE RELATORIO SET utentes=%d WHERE Data = %d''' %utentes %Data)
            
            c.execute('UPDATE FICHA_UTENTE SET Decisao = %d'%Decisao)
            ficha_utente = pd.DataFrame(c.fetchall(), columns=['ID_utente','Utente_nome','Data_nascimento','Genero','Localidade','ID_hospitalar', 'Data_Entrada','Hora_Entrada','Contacto_Telefonico','Pressao_Arterial','Ritmo_Cardiaco', 'Dificuldade_Respirar','Temperatura','Idade','Sugestao','Decisao'])
            print(ficha_utente)
            escolha_menu()
