Diagnóstico de Cancro da Mama com CNNs e Active Learning

Projeto Académico — Universidade de Coimbra
Deep LearningCNNActive LearningComputer VisionSaúdePythonTensorFlowmodAL

Objetivo: explorar como a Inteligência Artificial poderia contribuir para tornar o processo de análise de ecografias mamárias mais eficiente, apoiando a classificação das imagens e reduzindo a quantidade de dados que necessita de intervenção humana direta.

Para isso, desenvolvi uma CNN (Convolutional Neural Network) capaz de classificar ecografias em três classes — normal, benigno e maligno — e explorei uma abordagem de Active Learning com Human-in-the-Loop. A ideia foi avaliar se o modelo poderia identificar de forma iterativa as imagens mais relevantes para serem analisadas por um humano, tornando o processo de aprendizagem mais eficiente e reduzindo o esforço de anotação.

Stakeholder:

Num contexto hospitalar, esta abordagem poderia ser particularmente interessante em cenários com grandes volumes de exames e necessidade de anotação especializada, permitindo utilizar o conhecimento dos profissionais de forma mais direcionada.

Deteção precoce é decisiva na sobrevivência ao cancro da mama, mas a análise manual de ecografias exige elevada especialização e está sujeita a erros. Este projeto implementa uma CNN para classificar ecografias mamárias em 3 classes — normal, benigno e maligno — combinada com Active Learning para reduzir a quantidade de dados anotados necessários, incorporando um humano no ciclo de classificação (Human-in-the-Loop).

O dataset é composto por 780 ecografias mamárias (133 normais, 437 benignas, 210 malignas), claramente desbalanceado. Após data augmentation (rotação a 90º/180º e reflexão vertical), o conjunto ficou mais equilibrado: 798 normais, 874 benignas e 840 malignas.

O dataset é composto por 780 ecografias mamárias, distribuídas de forma desigual por 3 classes: 133 normais, 437 benignas e 210 malignas. Este desequilíbrio é particularmente evidente na classe "normal", que apresenta um número consideravelmente inferior de imagens face às restantes, o que representa um risco para a capacidade de generalização do modelo.

Distribuição de classes original — desbalanceada (Normal: 133, Malignant: 210, Benign: 437)

Para mitigar este desequilíbrio, foram aplicadas técnicas de data augmentation: rotação (90º e 180º) e reflexão vertical. Às classes "normal" e "malignant" foram aplicadas ambas as técnicas (rotação e reflexão), enquanto a classe "benign" recebeu apenas reflexão, já que partia de um número de imagens mais próximo do desejado. Com isto, o conjunto ficou mais equilibrado: 798 imagens normais, 874 benignas e 840 malignas — sem necessidade de recolher novos dados.

Distribuição após data augmentation (rotação e reflexão)

Arquitetura da CNN

  • Input(224,224,1) — imagens em escala de cinzas
  • 4 blocos de Conv2D (32, 64, 128 e 32 filtros) + BatchNormalization + MaxPooling2D, para extração progressiva de features
  • Dropout(0.3) após o 2º e o último bloco convolucional, para reduzir overfitting
  • Flatten → Dense(32, sigmoid) → Dense(3, softmax) para a classificação final nas 3 classes
  • Otimizador Adam (learning rate 0.00001), loss categorical_crossentropy

Active Learning

  • Implementado com a biblioteca modAL — ActiveLearner com a CNN como estimador
  • De 2009 imagens de treino, apenas 1000 usadas para o treino inicial; as restantes entram de forma iterativa no ciclo de Active Learning, uma imagem de cada vez classificada por um humano
  • 10 iterações de Active Learning, com warm_start=True para o treino não reiniciar a cada iteração
  • 3 experiências, cruzando 3 estratégias de query (uncertainty, entropy, margin sampling) com batch sizes de 32, 64 e 128, mais uma 4ª experiência com batch size 16

Resultados

  • Baseline de Passive Learning: 45,92% de precisão no conjunto de teste
  • Melhor configuração: margin sampling com batch size 16 — 68% de precisão no teste, superando o Passive Learning logo na primeira iteração
  • Por classe (batch 16): normal — precisão 68,5%, recall 77,5%; benigno — precisão 84,4%, recall 30,9% (a classe mais difícil de distinguir); maligno — precisão 55,4%, recall 85,1%
  • Com batch sizes maiores (64, 128) foi preciso mais iterações de Active Learning para ultrapassar o Passive Learning, confirmando que batches menores aceleram o ganho de precisão por imagem anotada
    • Matriz de confusão com a melhor configuração.
