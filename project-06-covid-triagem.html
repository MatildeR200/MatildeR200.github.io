Apoio à Decisão de Internamento de Doentes COVID-19

Projeto Académico — Universidade de Coimbra
ClassificaçãoKNNRegressãoPré-processamentoSaúdePythonNumPy

Objetivo: desenvolver e comparar modelos de classificação que apoiem a decisão médica na urgência: perante um doente com suspeita de COVID-19, prever se deve ficar internado para exames complementares ou se pode ter alta.

No momento da admissão, cada doente passa por uma triagem onde são registadas 8 variáveis — género, idade, estado civil, vacinação, dificuldade em respirar, ritmo cardíaco, pressão arterial e temperatura. Com base nestes dados de 600 doentes, e conhecendo a decisão final do médico, o problema foi tratado como uma tarefa de classificação supervisionada, implementada de raiz com NumPy.

Pré-processamento dos dados

  • Valores em falta: em 15 doentes não foi possível registar a pressão arterial (codificada como -1). Estes valores foram substituídos pela média dos valores válidos.
  • Outliers: foram identificados 10 valores anómalos no ritmo cardíaco, acima de 100 batimentos por minuto em repouso (o intervalo normal em adultos é de 60 a 100). Estes valores foram substituídos pela média.
Ritmo cardíaco dos 600 doentes — a vermelho, os valores anómalos identificados

Seleção de variáveis

Foi usado um método de filtro baseado na correlação de cada variável com a decisão de internamento. Foram selecionadas as quatro variáveis mais relevantes:

  • Idade: o principal fator de risco de COVID-19 grave, sobretudo a partir dos 60 anos.
  • Vacinação: os doentes não vacinados foram, na maioria, internados, enquanto os vacinados tiveram maioritariamente alta.
  • Dificuldade em respirar: um dos sintomas mais graves e característicos da doença, presente na maioria dos doentes internados.
  • Temperatura: a febre é um dos sintomas mais comuns.

O género apresentava uma correlação semelhante à da dificuldade em respirar, mas foi excluído por não ter fundamento clínico para esta decisão — um exemplo de como o conhecimento do domínio deve complementar a análise estatística.

Idade e vacinação dos doentes que tiveram alta (vermelho) e que foram internados (azul)

Modelos testados

  • Modelo regressivo: regressão linear pelo método dos mínimos quadrados, implementada a partir da fórmula matricial, com a saída arredondada para 0 (alta) ou 1 (internamento).
  • K-vizinhos mais próximos (KNN): cada doente é classificado de acordo com a decisão tomada nos 3 doentes mais parecidos, com base na distância euclidiana.
  • Regras individuais: modelo interpretável em que cada variável "vota" no internamento quando está acima da média, sendo a decisão final tomada por maioria.

Resultados

Os modelos foram avaliados com a sensibilidade (capacidade de identificar corretamente os doentes que devem ser internados), a especificidade (capacidade de identificar corretamente os que podem ter alta) e o F1-Score.

O KNN obteve os melhores resultados em todas as métricas. O modelo de regras individuais, apesar de mais simples de interpretar, falhou a maioria dos doentes que deviam ser internados — num contexto clínico, uma sensibilidade baixa é particularmente grave, porque corresponde a dar alta a doentes que precisam de cuidados.

Aplicação em contexto real

Um modelo deste tipo poderia ser integrado no sistema de triagem da urgência como ferramenta de apoio à decisão: com base nos dados recolhidos na admissão, sugeriria a probabilidade de internamento, ajudando a priorizar doentes e a antecipar a necessidade de camas em períodos de maior afluência.

  • Triagem mais rápida e consistente em períodos de grande pressão sobre as urgências.
  • Sinalização de doentes de risco que podem precisar de internamento.
  • Apoio à gestão de camas, antecipando o número provável de internamentos.

A decisão final continuaria sempre a ser do médico, sendo o modelo uma segunda fonte de informação.

O que faria hoje de forma diferente

Este foi um dos meus primeiros projetos de ciência de dados. Olhando para trás, há melhorias que hoje considero essenciais:

  • Separar dados de treino e de teste: os modelos foram avaliados nos mesmos dados usados para os construir, o que torna os resultados otimistas. Hoje usaria validação cruzada.
  • Normalizar as variáveis antes do KNN: como o KNN usa distâncias, variáveis com escalas maiores (como a idade) pesam mais do que as binárias (como a vacinação).
  • Tratar os valores em falta e outliers sem distorcer a média: calcular a média apenas com os valores válidos, ou usar a mediana, mais robusta a valores extremos.
  • Usar regressão logística em vez de regressão linear para um problema de classificação binária, e ajustar o limiar de decisão para privilegiar a sensibilidade.

#---------------------------------------- 3. TRANSFORMAÇAO DE DADOS

#-------------------------- 3.1 Seleção de variáveis 
# Optei por utilizar o Método de Filter (depende das carcteristicas das variaveis) onde utilizei os valores de correlação

# valores de correlaçao linear ou de pearson entre duas variaveis X e Y 

# entradas desejadas 

# col 0 genero

# col 2 estado civil

M = X.shape[1] # numero de colunas

VC = np.zeros(M) # valores de correlaçao
for i in range(0,M):
    c = np.corrcoef(X[:,i],Y)

# escolher o valor maximo em valor absoluto
VC = np.abs(VC)    # valor absoluto

print('\n:::::::::::: Metodo 2 - Uso de Correlação----------')
print('Valores de correlação',VC.round(4))

print()

# escolhi a idade, vacinação, dificuldade em respirar e temperatura

#-------------------------- 3.2 Resumir os dados

idAlta = np.where(IT == 0) # tem alta
idInternado = np.where(IT == 1) # fica internado


#-------media ---> idade
mediaIDA = ID[idAlta].mean().round() # media da idade dos doentes com alta
mediaIDI = ID[idInternado].mean().round() # media da idade dos doentes internados

print("Media da ID dos pacientes internados:",mediaIDI)
print()

#-------media ---> vacinação

print("Media dos pacientes VC com alta:",mediaVA)

#-------media ---> dificuldade em respirar

#-------media ---> temperatura

#-------------------------- 4.1 Modelo de Classificação

#------------ 1.modelo regressivo

# desenvolver os minimos quadrados   (Xt*X)^-1 * XT*y 

X1 = C [:,[1,3,4,7]]         # matriz das variaveis escolhidas

X1T = np.transpose(X1)       # transposta 
X1TX = np.dot(X1T,X1)        # produto de duas matrizes 
pInv = np.linalg.inv(X1TX)   # inversa de matrizes
M1 = np.dot(pInv,X1T)        # produto de duas matrizes 
PAR = np.dot(M1,Y)           # produto de duas matrizes  


Ye2 = np.dot(X1,PAR).round() # produto das variveis escolhidas c o parametro

        
#------------ 4.2 Avaliacao usando SE = sensibilidade e SP = especificidade           

# avalidacao - quantificar a qualidade do modelo de classificacao    

TT = 0
FP = 0
TN = 0
FN = 0

for i in range(0,N):
    if Y[i] == Ye2[i] and Y[i] ==1:
        TT += 1
    if Y[i] == Ye2[i] and Y[i] == 0:  
        TN += 1
    if Y[i] == 1 and Ye2[i] == 0:  
        FN += 1
    if Y[i] == 0 and Ye2[i] == 1:
        FP += 1
        
SE = TT/(TT+FN)
SP = TN/(TN+FP) 

Recall = SE
Precision = TT/(TT+FP)

Fscore = 2 * (Precision * Recall) / (Precision + Recall)

print("\n::::::::: MODELO REGRESSIVO ----------------")
print("SE - Sensibilidade >",round(SE,3))
print("SP - Especificidade > " ,round(SP,3))  
print("Fscore ",round(Fscore,3))


#------------ 2.metodo KNN

NK = 3  # numero de vizinhos mais próximos
varEscolhidas = C[:, [1, 3, 4, 7]]  # matriz --> utilizamos todas as linhas e colunas 1,3,4,7
YT = np.zeros(N)  # YT ---> Vector de distancias, matriz c zeros -- 600 lin

for i in range(0, N):
    
    Dist = np.zeros(N)
    Pontoi = varEscolhidas[i,:] # ponto i --- corresponde a linha i onde o ciclo percorre todas as linhas
    
    for j in range(0,N):
        
        Pontoj = varEscolhidas[j,:]
        Dist[j] = np.linalg.norm(Pontoi - Pontoj) # faz a norma entre o ponto i e j 
    
    indSort = np.argsort(Dist) # ordena os indices por ordem crescente
    classes = IT[indSort[0:NK]]
    classesi = classes.mean().round() # calcula a media
    YT[i] = classesi 


#------------ 4.2 Avaliacao usando SE = sensibilidade e SP = especificidade        

# avalidacao - quantificar a qualidade do modelo de classificacao       

TT = 0
FP = 0
TN = 0
FN = 0

for i in range(0,N):
    if Y[i] == YT[i] and Y[i] ==1:
        TT += 1
    if Y[i] == YT[i] and Y[i] == 0:  
        TN += 1
    if Y[i] == 1 and YT[i] == 0:  
        FN += 1
    if Y[i] == 0 and YT[i] == 1:
        FP += 1

        
SE = TT/(TT+FN)
SP = TN/(TN+FP) 

Recall = SE
Precision = TT/(TT+FP)

Fscore = 2 * (Precision * Recall) / (Precision + Recall)

print("\n::::::::: METODO KNN ----------------")

print("SP - Especificidade > " ,round(SP,3))  
print("Fscore ",round(Fscore,3))

        ITvacinaçao[i] = 1   # internado

        ITrespirar[i] = 1   # internado 
        
ITtemperatura = np.zeros(N)

        ITtemperatura[i] = 1   # internado
